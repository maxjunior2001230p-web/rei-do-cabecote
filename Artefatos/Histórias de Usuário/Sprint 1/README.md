# Histórias de Usuário da Sprint #1

## Gerenciamento de usuários pelo administrador

**Como** administrador, <br/>
**Eu quero** gerenciar os usuários no sistema (criar, editar, remover e atribuir permissões), <br/>
**Para** manter o controle de acesso e garantir a segurança do sistema. <br/>

## Gestão de peças pelo funcionário

**Como** funcionário, <br/>
**Eu quero** cadastrar, atualizar e remover peças, além de consultar o estoque disponível, <br/>
**Para** manter o inventário sempre atualizado e facilitar a gestão de produtos. <br/>

## Contato rápido do cliente via WhatsApp

**Como** cliente <br/>
**Eu quero** clicar em um botão para entrar em contato direto com a loja pelo WhatsApp, <br/>
**Para** obter atendimento rápido e tirar dúvidas sem dificuldades. <br/>

## Landing page para contato

**Como** cliente,<br/> 
**Eu quero** acessar uma landing page do sistema com informações e um canal de contato,<br/> 
**Para** conhecer melhor o negócio e entrar em comunicação com facilidade.<br/>
