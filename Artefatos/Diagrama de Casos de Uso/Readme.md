# Casos de uso 

## Administrador

### Gerenciar Usuários
Como Administrador, quero gerenciar os usuários no sistema, para controlar quem pode acessar o sistema.

### Visualizar Relatório de Faturamento
Como Administrador, quero visualizar um relatório de faturamento mensal, para acompanhar o desempenho financeiro do negócio.

## Funcionário

### Gerar Orçamentos
Como Funcionário, quero gerenciar os orçamentos, para criar, registrar e acompanhar as propostas de serviço para os clientes.

### Gerenciar Peças
Como Funcionário, quero gerenciar as peças, para controlar o estoque e os pedidos de peças sob demanda.

### Gerenciar Serviços
Como Funcionário, quero gerenciar os serviços, para registrar e acompanhar o status de cada manutenção realizada.

### Gerenciar Clientes
Como Funcionário, quero gerenciar os clientes, para manter um cadastro atualizado com o histórico de atendimentos.

### Fazer Login
Como Funcionário, quero realizar login no sistema, para acessar minhas ferramentas de trabalho diárias.

### Gerenciar Veículos
Como Funcionário, quero gerenciar os veículos, para associar os veículos aos clientes e manter um histórico de manutenções por veículo.

### Gerenciar Fornecedores
Como Funcionário, quero gerenciar os fornecedores, para ter um registro de contatos para compra de peças.

### Gerenciar Tempo de Garantia
Como Funcionário, quero gerenciar o tempo de garantia, para registrar e consultar o período de garantia de cada serviço prestado.

### Gerenciar peças para venda
Como Funcionário, quero gerenciar peças para venda, para controlar o estoque de peças prontas para venda.

## Cliente

### Entrar em contato pelo Whatsapp
Como Cliente, quero acessar o Whatsapp da Loja pelo site através de um botão, para conseguir entrar em contato com a empresa de forma rápida e fácil.

### Acessar Landing Page
Como Cliente, quero acessar a Landing Page, para conhecer a empresa, ver os serviços oferecidos e encontrar formas de contato.
