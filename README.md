# REI DO CABEÇOTE

Será desenvolvido um sistema simples e intuitivo para centralizar os processos da mecânica Rei do Cabeçote. A solução irá incluir cadastro de clientes e veículos, agendamento com calendário, geração de orçamentos, acompanhamento do status dos serviços e controle de pedidos de peças sob demanda. Além disso, haverá um dashboard financeiro básico para visualizar ganhos mensais e relatórios. O foco principal será a praticidade no uso, facilitando a organização do negócio.
